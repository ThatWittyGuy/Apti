# Shared — Data Visualization MCQs
### Applies to: JD1 (SAP Analytics Cloud), JD2 (Data & AI Engineering), any JD mentioning dashboards/reporting
> 35 Questions | 🟢 Easy | 🟡 Medium | 🔴 Hard

---

**Q1.** 🟢 What is the primary purpose of data visualization?
- A) To store data in a visual format
- B) To represent data graphically so patterns, trends, and insights can be understood quickly and communicated effectively
- C) To replace raw data tables with images
- D) To compress data for faster processing

**Answer: B**

---

**Q2.** 🟢 Which chart type is best for showing a trend over time?
- A) Pie chart
- B) Line chart
- C) Bar chart
- D) Scatter plot

**Answer: B**

---

**Q3.** 🟢 Which chart type is best for comparing proportions of a whole?
- A) Line chart
- B) Pie chart or Donut chart
- C) Histogram
- D) Box plot

**Answer: B**

---

**Q4.** 🟢 What is a "dashboard" in a business intelligence context?
- A) A car instrument panel integrated with SAP
- B) A visual display of key metrics and KPIs in an at-a-glance format, enabling quick monitoring of business performance
- C) A data entry form for business users
- D) An admin settings page in a BI tool

**Answer: B**

---

**Q5.** 🟢 What is a bar chart best used for?
- A) Showing distribution of a continuous variable
- B) Comparing discrete categories or groups against a quantitative value
- C) Displaying correlations between two variables
- D) Showing change over time only

**Answer: B**

---

**Q6.** 🟢 Which Python library is most commonly used for basic data visualization?
- A) NumPy
- B) Matplotlib
- C) Scikit-learn
- D) Pandas

**Answer: B**

---

**Q7.** 🟢 What does a scatter plot show?
- A) The distribution of a single variable
- B) The relationship or correlation between two continuous variables, with each point representing an observation
- C) Proportions of categories within a whole
- D) Change in a variable over time

**Answer: B**

---

**Q8.** 🟢 What is a histogram?
- A) A bar chart comparing multiple categories
- B) A chart showing the frequency distribution of a continuous variable by dividing it into bins
- C) A chart showing time series data
- D) A heat map of historical data

**Answer: B**

---

**Q9.** 🟡 What is a "heat map" and when is it most useful?
- A) A map showing geographic temperature data only
- B) A matrix visualization using color intensity to encode magnitude — useful for showing patterns across two categorical dimensions (e.g., correlation matrices, activity by hour/day)
- C) A chart for time series anomaly detection
- D) A visualization for hierarchical data

**Answer: B**

---

**Q10.** 🟡 What is a "box plot" (box-and-whisker plot) used for?
- A) Comparing proportions across categories
- B) Summarizing the distribution of a variable showing median, quartiles (IQR), and outliers — useful for comparing distributions across groups
- C) Tracking trends over time
- D) Displaying network relationships

**Answer: B**

---

**Q11.** 🟡 What does a "treemap" visualization show?
- A) An organizational chart of a company's tree structure
- B) Hierarchical data as nested rectangles sized proportionally to a quantitative value — good for showing part-to-whole relationships with hierarchy
- C) A decision tree model output
- D) A file system directory structure

**Answer: B**

---

**Q12.** 🟡 What is "Seaborn" in Python and how does it relate to Matplotlib?
- A) A standalone BI tool unrelated to Matplotlib
- B) A high-level statistical visualization library built on top of Matplotlib that simplifies creating attractive statistical graphics with less code
- C) A replacement for Matplotlib with a different syntax
- D) A library for interactive web-based charts

**Answer: B**

---

**Q13.** 🟡 What is "Plotly" used for compared to Matplotlib?
- A) Plotly is for static charts; Matplotlib is for interactive ones
- B) Plotly creates interactive, web-based visualizations (hover, zoom, filter) while Matplotlib primarily creates static charts — Plotly is preferred for dashboards and web apps
- C) Plotly is only for 3D charts
- D) They are identical libraries with different names

**Answer: B**

---

**Q14.** 🟡 What is "Tableau" and what is it used for?
- A) A Python library for tabular data processing
- B) A self-service BI and data visualization platform allowing users to connect to data sources and build interactive dashboards and reports with minimal coding
- C) A cloud database for analytics
- D) A data pipeline orchestration tool

**Answer: B**

---

**Q15.** 🟡 What is "Power BI" and who makes it?
- A) A SAP analytics tool
- B) Microsoft's business analytics and data visualization platform for creating interactive reports and dashboards, integrating with Microsoft's ecosystem (Excel, Azure, Teams)
- C) An open-source BI tool from Google
- D) A Python-based visualization framework

**Answer: B**

---

**Q16.** 🟡 What is the "data-ink ratio" principle in data visualization (Tufte)?
- A) The ratio of data points to chart labels
- B) The principle that visualizations should maximize the proportion of ink used to represent actual data and minimize non-data ink (gridlines, borders, decoration) — reducing chartjunk
- C) The ratio of color used vs. black ink in a chart
- D) The number of data series divided by chart size

**Answer: B**

---

**Q17.** 🟡 What is "chartjunk" in data visualization?
- A) Incorrectly formatted charts
- B) Unnecessary visual elements (decorations, 3D effects, excess gridlines, clipart) that add no informational value and make charts harder to read
- C) Charts made from junk/garbage data
- D) Outdated charts no longer used in a dashboard

**Answer: B**

---

**Q18.** 🟡 When should you avoid using a pie chart?
- A) When you have exactly two categories
- B) When you have many categories (>5), similar-sized slices, or need to make precise comparisons — bar charts are more effective in these cases
- C) When the data adds up to exactly 100%
- D) When displaying financial data

**Answer: B**

---

**Q19.** 🟡 What is a "waterfall chart" used for?
- A) Showing flowing data between nodes
- B) Visualizing how an initial value increases or decreases through sequential positive and negative contributions to reach a final value — commonly used for financial P&L analysis
- C) A chart showing cumulative rainfall over time
- D) A chart for tracking project milestones

**Answer: B**

---

**Q20.** 🟡 What is a "funnel chart" typically used for?
- A) Showing liquid flow through industrial funnels
- B) Visualizing sequential stages in a process where volume reduces at each stage — commonly used for sales pipeline, conversion rates, and user drop-off analysis
- C) Displaying hierarchical organizational data
- D) Comparing two datasets side by side

**Answer: B**

---

**Q21.** 🟡 What is "drill-down" functionality in a BI dashboard?
- A) A SQL technique for recursive queries
- B) The ability to click on a summary-level visual and navigate to increasingly granular levels of detail (e.g., from country → region → city → store)
- C) A data extraction method
- D) A way to delete data from a dashboard

**Answer: B**

---

**Q22.** 🟡 What is "cross-filtering" in interactive dashboards?
- A) Filtering data across multiple data sources simultaneously
- B) When selecting a data point in one visual automatically filters or highlights related data in other visuals on the same dashboard — enabling interactive exploration
- C) Applying multiple filters to a single chart
- D) A technique for filtering outliers from a dataset

**Answer: B**

---

**Q23.** 🟡 What is a "KPI card" or "scorecard" visual?
- A) A playing card displaying KPI names
- B) A simple visual showing a single key metric value, often with a comparison to a target or previous period and a color-coded status indicator (RAG: red/amber/green)
- C) A detailed table of all KPI calculations
- D) A chart showing KPI trends over 12 months

**Answer: B**

---

**Q24.** 🟡 What is "Matplotlib's `plt.subplot()`" used for?
- A) Creating sub-databases for plotting
- B) Dividing a figure into a grid of multiple axes/panels so several plots can be displayed in the same figure
- C) Plotting a subset of data points
- D) Creating a secondary y-axis on a single chart

**Answer: B**

---

**Q25.** 🟡 In data visualization, what is "color encoding" best practices?
- A) Using as many colors as possible to make charts visually appealing
- B) Using color purposefully and consistently to encode a specific data dimension — using sequential palettes for ordered data, diverging for deviation, and categorical for unordered groups; avoiding red/green for accessibility
- C) Always using a company's brand colors regardless of data type
- D) Using black and white only for professional reports

**Answer: B**

---

**Q26.** 🔴 What is "D3.js" and when would you use it over Tableau or Power BI?
- A) A Python data visualization library
- B) A JavaScript library for creating highly custom, interactive, web-based visualizations using SVG/Canvas — used when standard BI tools can't achieve the required custom visual design or interactivity
- C) A database visualization tool
- D) A 3D rendering engine for data art

**Answer: B**

---

**Q27.** 🔴 What is a "violin plot" and what does it show that a box plot doesn't?
- A) A chart shaped like a violin for aesthetic presentations
- B) A combination of box plot and kernel density estimate — showing the full probability distribution shape of the data in addition to median and quartiles, revealing multimodality that box plots miss
- C) A plot used exclusively for music industry data
- D) A scatter plot with violin-shaped confidence intervals

**Answer: B**

---

**Q28.** 🔴 What is "small multiples" (trellis/facet charts) in visualization?
- A) A technique for displaying very small datasets
- B) A grid of small charts using the same axes and scales but showing data for different subgroups — enabling easy comparison across categories without overplotting
- C) Reducing chart size to fit mobile screens
- D) Breaking one large dataset into multiple smaller datasets

**Answer: B**

---

**Q29.** 🔴 What is the difference between a "report" and a "dashboard" in BI?

**Answer: B**

**Q30.** 🔴 What is "storytelling with data"?
