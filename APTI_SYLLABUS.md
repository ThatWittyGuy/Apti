### ⭐ Highest-priority patterns for placements

If you're preparing specifically for **campus placements**, I'd prioritize:

**Number System:** Remainder → Divisibility → Unit digit → HCF/LCM → Factors
**Ratio:** Ratio division → Proportion → Ages → Mixtures
**Profit/Loss:** Successive discount → Marked price → Profit + discount
**Average:** Replacement → Combined average → Weighted average
**Time/Work:** Efficiency → Combined work → Alternate work
**TSD:** Average speed → Relative speed → Trains → Races
**P&C:** Arrangement → Selection → Restrictions
**Probability:** Cards → Dice → Coins → Balls → Conditional/at least
**Geometry:** Triangles → Circles → Area/volume
**Seating:** Linear → Circular → Conditional arrangements
**Ranking:** Rank from both ends → Interchange → Number of people → Ordering
